# Game UI Kit

Recreates the **chrome** around the arcade canvas — HUD (score/lives/level), pause overlay, and power-coin legend. The actual playfield is represented as a static composed scene using the pixel sprites from `assets/`. Toggle "Pause" to see the overlay.

Not a simulation — the real game ships as the `sigurd-startup` npm web component. Source reference: `jonasanders1/sigurd-startup-game/src/index.css` + sprite assets.
